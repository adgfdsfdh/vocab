  «Сохранено в словарь» / «Уже в словаре».

- Попутно (F02): варианты перевода берутся только для точного совпадения исходного слова — убран мусор
  вроде «пациента.» для «journey» (новый тест).

- `bash init.sh` → PASS, exit 0. Тесты: 34 / 34 (words.test.ts — 10, WordList.test.tsx — 4, App.test.tsx — 3, F02 — 17).
- Браузер (dev-сервер, реальный MyMemory): resilient, apple, journey → «Сохранено в словарь»; Apple → «Уже в словаре»;
  после перезагрузки «Слов: 3»; правка apple → «яблоко (фрукт)» сохранилась после перезагрузки и показывается на
  экране «Перевод»; поиск «фрукт» → 1 слово; удаление journey → в списке 2, в IndexedDB deleted=1.
