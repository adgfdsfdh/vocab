# Окно-виджет для Windows (Tauri 2)

Маленькое окно 360×500 поверх всех окон. Открывает сайт https://adgfdsfdh.github.io/vocab/?compact=1,
поэтому обновления сайта появляются в окне сами — пересобирать программу не нужно.

## Установка
1. Запустить `src-tauri\target\release\bundle\msi\Vocab_0.1.1_x64_ru-RU.msi`.
   Подписи кода нет, поэтому Windows может показать «Windows защитила ваш компьютер» →
   «Подробнее» → «Выполнить в любом случае».
2. Окно откроется само. В нём нужно один раз войти: вкладка «Аккаунт» → письмо со ссылкой придёт
   на почту → скопировать ссылку из письма и вставить в поле «Ссылка или код из письма».

## Как пользоваться
- **Ctrl+Shift+Space** — показать окно (курсор сразу в поле ввода) / спрятать.
- Полоса сверху: потянуть мышью — передвинуть окно; ползунок — прозрачность; «—» — спрятать.
- Иконка в трее (у часов): «Показать», «Прозрачность ▸», «Запускать вместе с Windows», «Выход».
- Alt+F4 только прячет окно. Закрыть программу совсем — «Выход» в трее.
- Прозрачность делает сама Windows (сквозь окно видно, что позади), не меньше 30% видимости.
- Позиция, размер и прозрачность запоминаются (`%APPDATA%\io.github.adgfdsfdh.vocab`).

## Сборка (для разработчика)
Нужны Rust и Visual Studio Build Tools (уже стоят). Команда: `npm run desktop:build`
(первый раз 3–5 минут; WiX для .msi скачивается сам, бесплатно).
