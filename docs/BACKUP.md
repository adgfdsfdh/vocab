# Бэкап словаря

Всё бесплатно: Node + Планировщик заданий Windows. Google Диск и Google API не используются.
При каждом входе в Windows (через минуту) запускается `scripts/backup.mjs`. Если копии за сегодня ещё нет,
он берёт все слова и результаты тренировок из Supabase и кладёт файл `vocab-ГГГГ-ММ-ДД.json` в папку на ПК
(сейчас `D:\VocabBackup`). Хранятся 10 последних копий, старые удаляются сами.

## Настройки (.env.local, в git не попадает)
```
SUPABASE_SECRET_KEY=sb_secret_...   # секретный ключ Supabase; без VITE_ — в сайт не попадает
BACKUP_DIR=D:\VocabBackup
```

## Команды
- Сделать копию сейчас (даже если сегодня уже была): `node scripts/backup.mjs --force`
- Поставить / обновить задачу: `powershell -ExecutionPolicy Bypass -File scripts\install-backup-task.ps1`
- Журнал запусков: `backups\backup.log` (в нём нет ключей и путей).
- Задача видна: Пуск → «Планировщик заданий» → Библиотека → **Vocab backup**.
  При запуске на секунду может мелькнуть чёрное окно — это нормально.

## Восстановить слова
Приложение → **Аккаунт → Резервная копия → Импорт** → выбрать файл из `D:\VocabBackup`.
Дубликаты не создаются: берутся только новые слова и более свежие изменения.
Кнопка **Экспорт** там же скачивает такой же файл с этого устройства (работает и без интернета).

## Если что-то пойдёт не так
Ключ засветился — Supabase → Project Settings → API Keys → Secret key → **Roll**, вписать новый в `.env.local`.
