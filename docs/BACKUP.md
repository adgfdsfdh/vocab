# Бэкап словаря (один раз настроить)

Всё бесплатно: программа «Google Диск для компьютера» + Планировщик заданий Windows. Google API не нужен.
Каждый день в 13:00 на ПК запускается `scripts/backup.mjs`: он берёт все слова и результаты тренировок
из Supabase и кладёт файл `vocab-ГГГГ-ММ-ДД.json` в папку на Google Диске. Хранятся 10 последних копий.
Если ПК в 13:00 был выключен, бэкап сделается вскоре после включения.

## 1. Google Диск для компьютера
1. Скачайте с https://www.google.com/drive/download/ → **Скачать Диск для компьютера**, установите.
2. Войдите в свой Google-аккаунт (сами). В проводнике появится диск **G:** («Мой диск»).
3. Создайте на нём папку `VocabBackup`.

## 2. Секретный ключ Supabase → .env.local
Скрипту нужен ключ, который видит все записи. Он хранится **только** в `.env.local` на этом ПК
(файл не попадает в git, а ключ без префикса `VITE_` не попадает в сайт и приложение).
1. Supabase → **Project Settings → API Keys** → раздел **Secret keys** → скопировать ключ (`sb_secret_...`).
   Если показан старый вид — ключ **service_role**.
2. Откройте `.env.local` Блокнотом и добавьте в конец две строки (без кавычек и пробелов вокруг `=`):
   ```
   SUPABASE_SECRET_KEY=sb_secret_...
   BACKUP_DIR=G:\Мой диск\VocabBackup
   ```
3. Сохраните. В чат ключ не присылайте.

## 3. Проверить вручную
В папке проекта: `node scripts/backup.mjs` → должно написать `OK слов: N ...`, а в `G:\Мой диск\VocabBackup`
появится файл с сегодняшней датой. Журнал запусков: `backups\backup.log` (в нём нет ключей и путей).

## 4. Задача в Планировщике
`powershell -ExecutionPolicy Bypass -File scripts\install-backup-task.ps1`
Проверка: Пуск → «Планировщик заданий» → Библиотека → задача **Vocab backup**
(можно нажать «Выполнить», чтобы проверить). При запуске на секунду мелькнёт чёрное окно — это нормально.

## Восстановить слова
Приложение → **Аккаунт → Резервная копия → Импорт** → выбрать файл `vocab-....json`.
Дубликаты не создаются: берутся только новые слова и более свежие изменения.
Кнопка **Экспорт** там же скачивает такой же файл с этого устройства (работает и без интернета).
